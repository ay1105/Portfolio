# Vercel Deployment Configuration

This file tells Vercel how to deploy your static portfolio website.

## What this does:
- Serves your `index.html` as the main page
- Handles all routes by redirecting to `index.html` (for single-page application behavior)
- Uses Vercel's static file serving for optimal performance

## Files included:
- `index.html` - Your main portfolio page
- `NEW-RESUME.pdf` - Your resume file
- `pp.webp` - Your profile picture


Your portfolio is ready for deployment!
